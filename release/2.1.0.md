## Release identity

- Target release: `2.1.0`
- Target tag: `v2.1.0`
- Release inputs: `release/release-inputs.json`, `status: draft`
- Runtime source and image digests: unset until preparation

## Scope

One preparation command produces the complete release PR. Signed tags bind the
committed inputs, evidence, templates, and notes; publication uploads notes only.

## Migration

Release operators use `make release-prepare RUN=<id>` in place of separate
evidence generation, repinning, finalization, and manifest commands. Current
tooling accepts only release-inputs v3. Waived IDs move out of
`evidence_record_ids` into `evidence_waivers`; historical records retain their
observations and bindings. Historical validators remain available at their tags.
Consumers no longer receive standalone manifest/checksum/certificate assets for
new releases. No consumer runtime configuration change is required.
