> manifest validates against the final release inputs.

## Release identity

- Target tag: `v1.0.1`
- Release inputs: `release/release-inputs.json`, currently `status: draft`

## Scope

This patch release carries the post-1.0.0 fixes and release-readiness work. The
Cursor CLI remains an opt-in substitute reviewer with a separate credential and
egress path. SPEC-21 acceptance is a release-gating candidate for 1.0.1, not a
claim that the historical 1.0.0 Cursor runs certify this release.

## 1.0.1 release gates

- Run the current evidence matrix against one frozen runtime source and final
  base/reviewer image pair.
- Complete the canonical [SPEC-21 Cursor acceptance checklist](../docs/improvement-specs/spec-21-cursor-cli-reviewer.md#101-closure-checklist),
  including the explicit ask-mode product decision.
- Record only sanitized evidence and keep private consumer coordinates out of
  the public repository.
- Activate the release inputs only after all release-gating records bind to the
  same source and image digests.

## Finalization

After the release commit and tag exist, build and validate the external manifest
with the 1.0.1 coordinates, publish the manifest/checksum, and update this file
from draft notes to final release notes in the release commit.
