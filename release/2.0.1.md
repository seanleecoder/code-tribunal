## Scope

- Release preparation is now one evidence-and-pin PR. The canary owns image identity, selectable zero-token lifecycle and hostile campaigns generate their own records, and release commands produce active inputs, final notes, CHANGELOG, and certificate assets through the existing validators.

- Failed accepted resolve/reopen commands fail `post` with `partial_failed`, preserve the prior disposition, and allow a later retry. Findings remain informational.
- Current documentation checks catch missing concrete repository paths and test definitions during ordinary PRs.
