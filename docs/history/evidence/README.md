# Historical evidence link

The `v1.0.0` release notes link to this historical path. The evidence index and
runbook are now maintained at [`docs/evidence/`](../../evidence/README.md), with
the 1.0.0 results retained in that index's historical matrix.

The exact active release-inputs artifact used by 1.0.0 is preserved at
[`release/history/1.0.0-release-inputs.json`](../../../release/history/1.0.0-release-inputs.json).
It retains the historical runtime/image identity, CI and publication run IDs,
cited records, and SPEC-34 waiver. It is a provenance snapshot and is not
validated against current checked-file hashes. The current
`release/release-inputs.json` is a fresh 1.0.1 draft and must not be used to
reinterpret the 1.0.0 release.

This redirect exists to keep the frozen release notes self-consistent; it is not
a second evidence record or release-gating source.
