# Historical evidence link

The tagged `v1.0.0` release notes link to this historical path and describe the
release-time state. The current evidence index and runbook are maintained at
[`docs/evidence/`](../../evidence/README.md). The 1.0.0 results are retained in the
historical matrix of the
[`v2.0.3` evidence index](https://github.com/seanleecoder/code-tribunal/blob/v2.0.3/docs/evidence/README.md).

The historical release inputs remain available at
`v1.0.0:release/release-inputs.json`.

This redirect exists to keep the frozen release notes self-consistent; it is not
a second evidence record or release-gating source.
